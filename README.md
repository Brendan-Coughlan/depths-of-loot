# Game Concept

_Depths of Loot_ is a 2D roguelike dungeon crawler where players descend into a dangerous, ever-resetting dungeon to fight monsters, collect loot, and make strategic decisions about when to escape. The deeper they go, the greater the rewards—but death results in losing everything collected during that run.
